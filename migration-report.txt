Limits and deliberate Source adaptations
  Common soldier, Skeleton variants, Suicide Grunt and Armored Heavy enemy types are implemented.
  Static prop collision uses a convex box from native mesh bounds.
  Dedicated half ragdolls use native cut mesh groups with the matching subset of physics bodies.
  Partial scalp/jaw cut sources remain archived; they are not separate gameplay head-wound states.
  Source converts native ragdoll shapes/joint axes to its independent XYZ constraints.
  The 70 kg common ragdoll mass is the export setting, not a recovered native body weight.
  Head/neck look pose ranges come from shared Sniper look clips, not decoded Undead AI limits.
  Native gun clips contain footsteps but no gun-fire markers; start/end windows and fire rate
  are explicit addon integration settings, based on authored raise/recoil/lower poses.
  Thompson uses its native Player loop-end event (which references an MP40 sample);
  no dedicated Thompson NPC loop-end event was found. Luger uses named Pistol02 gun samples.
  The pentagram uses the native texture with a bounded Source sprite reconstruction.
  Native binary FX operators and the original AI chance values are not fully decoded.
  42 common sound events have unbound native slots 105/106/107/117.
  Their QC events and audit records are retained; no unrelated sound was substituted.
  One native jaw-gib LOD contains non-finite UVs; its valid original LOD0 is used instead.
  StudioMDL welds very close vertices and discards tiny slivers/duplicate zero-area faces;
  geometry validation checks that authored visible limbs and surfaces survive at every LOD.
